# Vehicle Service Management System

## Tech Stack
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- JWT Authentication

## Features
- Customer Management
- Vehicle Management
- Service Request Management
- JWT Login
- Pagination
- Search APIs
- Soft Delete
- Swagger Documentation

## Run Project

pip install -r requirements.txt

uvicorn main:app --reload
